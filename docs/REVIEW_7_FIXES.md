# 리뷰 #7 수정 기록 — 0.1.2

리뷰 대상은 0.1.1 출시 커밋 `acffbbf2`다. 아래 수정은 0.1.2에 포함한다.
기존 0.1.1의 제목과 PR #17 불릿 배치는 유지한다.

| 항목 | 변경과 검증 |
| --- | --- |
| B-1 커스텀 면제 훅 | 내부 콜백의 디코딩 계약을 `ContextVar`로 전달한다. `super().is_exempt(path)`와 `super().is_exempt(str(path))` 모두 리터럴 `?`를 보존한다. 직접 호출하는 공개 `is_exempt("/input?query")`는 쿼리를 무시하는 기존 계약을 유지한다. 예외 후 복구·스레드 간 격리와 ASGI/Axum × 메모리/실제 Redis를 검사한다. |
| A-1 버전 API | 타입 힌트가 있는 `pynext.__version__`은 설치된 `pynext-framework` 메타데이터를 읽는다. 별도 버전 문자열을 중복 관리하지 않는다. |
| A-2 네이티브 버전 | 세 크레이트가 워크스페이스의 0.1.2를 상속하며 Cargo.lock도 맞춘다. `_native.__version__`은 컴파일 시 크레이트 버전이다. 모든 휠의 별도 설치 검사에서 파일명·배포 메타데이터·Python API·컴파일 버전 일치를 확인한다. |
| A-3 빈 제목 | 빈 `Unreleased` 제목을 제거했다. |
| B-2 헬스 경로 | 네이티브 제한 검사와 정적 응답 분기가 동일한 단일 디코딩 결과를 사용한다. 정적 파일과 이름이 겹쳐도 인코딩된 프로브가 프레임워크 상태를 반환한다. ASGI/Axum·개발/프로덕션·리미터 없음/소진 상태에서 GET/HEAD와 시작 전·시작 후·드레인을 검사한다. |
| B-3 취소 기록 | 네이티브 기한 초과와 ASGI 연결 해제의 동기 핸들러가 모두 500으로 기록됨을 재현했다. 전송 계층의 취소 사유를 유지해 504/499로 기록한다. 로그·메트릭·작업 용량 유지·후속 쓰기 차단을 함께 검사한다. |
| N11 항목 수 | 작업 기준 main `d532f70`에는 지적된 “23개” 문구가 없다. 현재 0.1.1절은 최상위 불릿 47개이며, 과거 검토의 22개와 범위가 다르다. 근거 없는 22개 표기나 기존 출시 항목 재배치는 추가하지 않았다. |

## 재현 결과

- B-1: 같은 22개 테스트로 수정 전 **13개 실패·9개 통과**, 수정 후 **22개 통과**.
  HTTP 우회는 404가 제한 없이 반환되는 경로에서 확인했다. WebSocket의 리터럴
  `?` 경로는 라우터가 먼저 거부하므로 이를 429 우회 재현으로 세지 않는다.
  별도로 정상 면제 업그레이드·소진된 버킷 거부·인코딩된 경로의 미수락을 검사했다.
- B-2: 같은 8개 테스트에서 기존 네이티브의 리미터 없는 개발/프로덕션 2개가
  `asset shadow`를 반환해 실패하고 나머지 6개는 통과했다. 수정 후 8개 모두 통과했다.
- B-3: 기존 동기 작업 용량 테스트에 로그·메트릭 검사를 추가하자 두 전송 모두
  500으로 실패했다. 수정 후 실제 504와 관측용 499로 각각 기록된다.
  취소 신호 설정과 코루틴 취소 사이에 작업 스레드가 먼저 협력적으로 종료하는
  순서도 재현했다. 이때의 `RequestCancelled`도 실제 기한 상태를 유지하고
  애플리케이션 오류/500으로 변환하지 않는다. 취소 신호 없이 직접 발생시킨
  같은 예외는 기존 애플리케이션 오류 처리를 유지한다.
- 추가 정적 경로 검사: 리미터가 있으면 정적 빠른 경로를 끄던 잔여 조건을 발견했다.
  메모리/실제 Redis 두 사례에서 GET·HEAD·304·206이 Python dispatch를 거치는
  실패를 재현하고 조건을 제거했다. 각 요청의 단일 과금과 소진 후 429를 함께
  검사한다. 명시적 미들웨어와 Origin 정책을 위한 Python 경로는 유지한다.

```bash
uv run --locked --all-extras pytest -q tests/test_exemption_delegation.py tests/test_encoded_health.py tests/test_sync_cancellation.py tests/test_release_version.py
```

## 남은 방향

이미 실행 중인 동기 코드와 외부 쓰기의 강제 취소·롤백은 제공하지 않는다.
리미터의 늦은 완료가 토큰을 소비할 수 있는 R3 경계도 유지된다.
각각 [동기 작업 계약](RUNTIME_HARDENING.md)과 [ASGI 판정 계약](ASGI_ADMISSION.md)을 따른다.
적용 범위는 계속 **소규모 웹·통제된 기능 검증**이며, 공개 운영 적합성의 기준과
후속 방향은 [전체 로드맵](PRODUCTION_ROADMAP.md)에서 관리한다.
