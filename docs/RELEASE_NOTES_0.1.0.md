# PyNext 0.1.0 릴리스 초안

상태: **준비 중, 미게시**. 패키지 버전은 `0.1.0`, 새 Git 태그는 `0.1.0v`다.
기존 `v0.1.0` 태그는 과거 스냅샷을 가리키며 변경하지 않는다. 이 버전 번호는
개발 후보 `0.7.0a1`보다 낮으므로 기존 설치의 자동 업그레이드로 선택되지 않을 수 있다.

주요 변경 사항:

- 모든 앱 HTTP 경로의 전역 미들웨어, multipart 폼·업로드, 개발 오류 페이지와 프로젝트 생성 CLI.
- 수명주기 리소스, SQLite 서버 세션, 세션에 결합된 CSRF와 인증·권한 검사 연결점.
- SQLite 및 Redis 공유 ISR, Redis 공유 요청 제한, 빌드·쿼리별 캐시 키와 워커 간 무효화.
- 설정 가능한 WebSocket 메시지 한도, 서브프로토콜 협상과 프로세스 내 게시·구독.
- SSG 빌드에서 비동기 청크 생성, 첫 ISR 요청의 스트리밍과 완성된 응답 캐싱.
- Python 클라이언트 DSL의 연쇄 비교, 컬렉션 비교와 유니코드 처리 개선.
- 서버와 브라우저가 공유하는 제한된 island 모델을 통한 DOM 보존 hydration.
- 모든 페이지의 클라이언트 탐색, 공개 응답에 한정된 prefetch 캐시, 로컬 이미지 WebP 변환.
- 네이티브 개발 파일 감시와 JS/TS island 모듈 교체, 공유 리스너 기반 다중 워커, Linux standalone 디렉터리.
- 실제 OpenTelemetry SDK, ASGI·Axum 및 브라우저 회귀 검사 강화.

지원 및 제한: Python 3.13·3.14와 Axum·ASGI를 Linux에서 검증했다. macOS·Windows
조합은 CI 설정만 추가했으며 아직 결과를 확인하지 않았다. 공유 island 모델은 텍스트와
문자열 props 등 제한된 부분집합이다. 개발 모드 HMR은 JS/TS island 모듈에 한정되며
해당 island의 상태 보존을 보장하지 않는다. Windows 다중 워커의 런타임 검증은 남아 있다.
Redis와 이미지 최적화에는 각각 선택적 의존성이 필요하다. Linux standalone은 호환되는
운영체제와 시스템 라이브러리가 필요하다. React/RSC 호환성은 비목표이며, 현재
프레임워크는 인터넷에 직접 노출하거나 신뢰할 수 없는 앱을 실행할 수 있도록 보안
강화가 완료되지 않았다. 남은 작업은 [로드맵](ROADMAP.md)에 기록한다.

게시 전 현재 커밋의 전체 테스트와 OS·배포 조합 CI, 배포 패키지 설치, 버전과 태그
충돌, 공개 대상의 인증 및 권한을 확인한다. 이 문서는 게시가 완료되었다는 뜻이 아니다.
